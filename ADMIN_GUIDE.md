# Инструкция администратора сайта

Документ описывает, как пользоваться административной частью сайта ювелирной мастерской и что важно учитывать при работе с заявками.

## 1. Назначение административной части

Административная часть нужна для просмотра заявок, которые клиенты отправляют через форму на странице `request.html`.

На текущем этапе администратор может:

- просматривать список заявок;
- видеть дату, имя клиента, контакт, тип услуги, бюджет и комментарий;
- менять статус заявки;
- смотреть количество заявок по статусам.

## 2. Запуск сайта

Обычные HTML-страницы можно открыть напрямую через файл `index.html`, но в таком режиме заявки не сохраняются.

Чтобы работала форма заявки и административная страница, сайт нужно запускать через Flask:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Если команда `python` открывает Microsoft Store или не запускает проект, можно попробовать:

```powershell
py -3 app.py
```

После запуска сайт обычно доступен по адресу:

```text
http://127.0.0.1:5000/
```

## 3. Основные адреса

- Главная страница: `http://127.0.0.1:5000/`
- Форма заявки: `http://127.0.0.1:5000/request.html`
- Вход администратора: `http://127.0.0.1:5000/admin/login`
- Страница администратора: `http://127.0.0.1:5000/admin/requests`

Административная страница закрыта простым входом по паролю. В учебной версии пароль по умолчанию:

```text
admin
```

Для изменения пароля перед запуском сайта можно задать переменную окружения `ADMIN_PASSWORD`:

```powershell
$env:ADMIN_PASSWORD = "новый_пароль"
python app.py
```

## 4. Работа с заявками

Когда клиент отправляет форму, заявка сохраняется в локальную базу данных SQLite.

Перед просмотром заявок нужно открыть `/admin/login` и ввести пароль администратора. После входа сайт перенаправит на страницу `/admin/requests`.

На странице `/admin/requests` отображается таблица заявок. В таблице есть:

- номер заявки;
- дата создания;
- текущий статус;
- имя клиента;
- контакт для связи;
- тип услуги;
- ориентировочный бюджет;
- комментарий клиента.

Чтобы изменить статус заявки:

1. Открыть страницу `/admin/requests`.
2. Найти нужную заявку в таблице.
3. Выбрать новый статус в выпадающем списке.
4. Нажать кнопку `Сохранить`.

Над таблицей находится фильтр заявок. С его помощью можно быстро показать:

- все заявки;
- только новые заявки;
- заявки в работе;
- завершенные заявки.

Фильтр меняет только отображение таблицы и не удаляет заявки из базы данных.

Для выхода из административной части нужно нажать кнопку `Выйти` в верхнем меню. После выхода страница заявок снова потребует пароль.

## 5. Статусы заявок

В проекте используются три статуса:

- `Новая` - заявка только поступила и еще не обработана.
- `В работе` - заявка просмотрена, по ней идет уточнение или выполнение.
- `Завершена` - обращение обработано или работа по нему закончена.

Сверху страницы администратора отображаются счетчики по каждому статусу.

## 6. Где хранятся заявки

Заявки сохраняются в файл базы данных:

```text
data/site.db
```

Этот файл создается автоматически при запуске сайта. Он не отправляется в git, потому что содержит локальные данные заявок.

Важно:

- удаление файла `data/site.db` приведет к потере сохраненных заявок;
- перед очисткой или переносом проекта желательно сделать копию базы;
- базу данных не следует публиковать в открытом доступе, так как в ней могут быть контакты клиентов.

## 7. Что важно знать администратору

Текущая административная страница защищена простым паролем. Это учебная защита, подходящая для демонстрации проекта в рамках практики. Для реального сайта потребуется полноценная система пользователей, безопасное хранение паролей и настройка секретного ключа сессии.

В проекте также есть служебная иконка сайта `favicon.svg`. Она подключена к страницам и используется браузером во вкладке. Для совместимости Flask также обрабатывает адрес `/favicon.ico`, чтобы в консоли не появлялся лишний статус `404` по этому запросу.

Для реального использования нужно будет доработать:

- полноценный вход администратора по логину и паролю;
- защиту персональных данных клиентов;
- удаление или архивирование старых заявок;
- возможность прикреплять фотографии изделий;
- полноценное управление каталогом и ценами.

## 8. Как заменить иконку и изображения

Иконка сайта хранится в файле:

```text
favicon.svg
```

Чтобы заменить иконку, нужно отредактировать этот файл или заменить его другим SVG-файлом с тем же названием. Все HTML-страницы уже подключают `favicon.svg`, поэтому дополнительно менять каждую страницу обычно не нужно.

Главное изображение в верхнем блоке страниц задается в CSS-файле:

```text
static/css/styles.css
```

Нужно найти правило `.hero` и строку с `url(...)`. Сейчас там используется внешняя ссылка на изображение. Если нужно поставить свою картинку, удобнее добавить файл в папку проекта, например:

```text
static/img/hero.jpg
```

После этого в `styles.css` можно заменить ссылку:

```css
url("../img/hero.jpg")
```

При замене изображений важно:

- использовать понятные названия файлов без пробелов;
- не удалять затемняющий слой `linear-gradient`, потому что он помогает тексту читаться поверх изображения;
- после замены открыть сайт на компьютере и телефоне и проверить, что текст не сливается с фоном;
- если браузер показывает старую иконку, обновить страницу с очисткой кэша или открыть сайт в новом окне.

## 9. Как изменить цвета сайта

Основные цвета сайта находятся в начале файла:

```text
static/css/styles.css
```

В блоке `:root` указаны переменные цвета:

- `--bg` - основной фон сайта;
- `--panel` - фон карточек и крупных блоков;
- `--text` - основной цвет текста;
- `--muted` - второстепенный текст;
- `--line` - цвет границ;
- `--primary` - золотой акцент для кнопок и важных элементов;
- `--accent` - серебристый дополнительный акцент.

Текущий визуальный стиль сделан в темных тонах с золотыми и серебристыми акцентами. Если нужно изменить дизайн, лучше сначала менять значения переменных в `:root`, а не править каждый блок отдельно.

После изменения цветов нужно проверить:

- главную страницу;
- страницу заявки;
- страницу `/admin/requests`;
- мобильную версию сайта.

Важно следить, чтобы текст оставался читаемым на темном фоне, а кнопки и поля формы были хорошо видны.

## 10. Частые проблемы

Если заявка не сохраняется, нужно проверить, что сайт открыт через адрес `http://127.0.0.1:5000/`, а не напрямую через файл.

Если страница администратора не открывается, нужно убедиться, что Flask-сервер запущен командой `python app.py`.

Если порт `5000` занят, Flask может не запуститься. В таком случае нужно закрыть другой запущенный сервер или изменить порт запуска в `app.py`.

Если в консоли снова появляется запрос `/favicon.ico` со статусом `404`, нужно проверить наличие файла `favicon.svg` и маршрутов `/favicon.svg` и `/favicon.ico` в `app.py`.
