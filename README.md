# Praktica3kyrs

Учебный проект сайта ювелирной мастерской для малого бизнеса. Сайт содержит публичную витрину, форму заявки, личный кабинет клиента и простую административную часть для обработки обращений.

## Что реализовано

- 12 публичных HTML-страниц.
- Адаптивная верстка для компьютера и телефона.
- Единое верхнее меню, хлебные крошки и подвал с ФИО автора.
- Форма заявки клиента.
- Backend на Flask.
- Хранение данных в SQLite.
- Регистрация и авторизация клиентов.
- Личный кабинет клиента с историей заявок.
- Отслеживание статуса заявки в личном кабинете.
- Чат клиента и администратора внутри заявки.
- Административный вход по паролю.
- Просмотр заявок и изменение статусов.
- Каталог изделий с фото, описанием и ценой.
- Портфолио проданных изделий и выполненных работ.
- Загрузка и удаление фотографий каталога и портфолио через админку.
- Случайные фото из каталога и портфолио на главной странице.
- Формирование документа заявки в формате `.docx`.

## Технологии и версии

Проект проверялся в локальной среде:

- Python 3.12.13;
- Flask 3.1.3;
- SQLite;
- HTML5;
- CSS3;
- JavaScript.

Зависимость проекта указана в файле `requirements.txt`:

```text
Flask>=3.0,<4
```

Для формирования `.docx` отдельная библиотека не требуется: документ создается средствами стандартной библиотеки Python через ZIP-структуру Office Open XML.

## Запуск проекта

1. Открыть папку проекта.
2. Создать виртуальное окружение.
3. Установить зависимости.
4. Запустить Flask-приложение.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Если Python установлен через Microsoft Store и команда `python` работает некорректно, можно попробовать:

```powershell
py -3 app.py
```

После запуска сайт доступен по адресу:

```text
http://127.0.0.1:5000/
```

Для размещения на хостинге можно задать переменные окружения:

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "10000"
python app.py
```

## Основные адреса

## Учетные данные

Администраторская часть закрыта учебным паролем:

```text
admin
```

Пароль задается в `app.py`:

```python
ADMIN_PASSWORD = os.environ.get("ADMIN_PASSWORD", "admin")
```

При необходимости пароль можно поменять без изменения кода:

```powershell
$env:ADMIN_PASSWORD = "new_password"
python app.py
```

Клиентские аккаунты создаются через страницу регистрации `/register`. После регистрации пользователь попадает в личный кабинет.

В проекте используются три сценария доступа:

- неавторизованный посетитель может смотреть публичные страницы и оставить заявку;
- авторизованный клиент может смотреть историю своих заявок, статус, переписку и документ заявки;
- администратор может обрабатывать заявки, менять статусы, отвечать клиентам, вести каталог и портфолио.

## Как проверить основные сценарии

1. Открыть `/register` и создать клиента.
2. Перейти на `/request.html` и отправить заявку.
3. После отправки открыть карточку заявки в личном кабинете.
4. Написать сообщение в чате заявки.
5. Открыть `/admin/login` и войти с паролем `admin`.
6. Открыть заявку в админке, изменить статус и отправить ответ клиенту.
7. Вернуться в личный кабинет клиента и проверить новый статус и сообщение.
8. Нажать `Скачать документ` в карточке заявки и проверить файл `.docx`.

## Данные и файлы

Локальная база данных создается автоматически:

```text
data/site.db
```

В базе хранятся:

- заявки клиентов;
- статусы заявок;
- типы услуг;
- клиенты;
- сообщения чата;
- изделия каталога;
- работы портфолио.

Фотографии, загруженные через админку, сохраняются в папку:

```text
static/uploads/
```

После перезапуска Flask данные сохраняются, если не удалять `data/site.db` и файлы из `static/uploads/`.

## Статическая проверка

Большинство публичных страниц можно открыть напрямую через файл `index.html`. Это удобно для проверки внешнего вида, но форма заявки, личный кабинет, чат, загрузка изображений и `.docx`-экспорт работают только при запуске через Flask.

## Хостинг

Для бесплатного размещения Flask-проекта можно рассмотреть:

- PythonAnywhere: простой вариант для учебного Flask-сайта, есть бесплатный аккаунт и домен вида `username.pythonanywhere.com`;
- Render: есть бесплатные web services, но у бесплатного тарифа файловая система временная, поэтому SQLite-база и загруженные изображения могут теряться при перезапуске или redeploy.

Для текущей версии с SQLite и загружаемыми файлами проще начать с PythonAnywhere. Если размещать проект на Render, лучше заранее перенести хранение данных в PostgreSQL и вынести изображения во внешнее хранилище.

## Структура репозитория

В репозитории хранится исходный код сайта, статические страницы, стили, скрипты, документация и служебные настройки проекта.

```text
app.py                  Flask-приложение: маршруты, SQLite, заявки, кабинет, админка и DOCX
requirements.txt        зависимости проекта
README.md               инструкция запуска, адреса страниц и структура репозитория
ADMIN_GUIDE.md          инструкция администратора
.gitignore              исключения для временных файлов, базы и загруженных изображений
favicon.svg             иконка сайта
index.html              главная страница
about.html              страница о мастерской
services.html           услуги
catalog.html            каталог изделий
portfolio.html          портфолио работ
prices.html             цены
materials.html          материалы
warranty.html           гарантия
care.html               уход за изделиями
faq.html                частые вопросы
contacts.html           контакты
request.html            форма заявки
static/css/styles.css   стили сайта
static/js/main.js       JavaScript для мобильного меню и формы
static/uploads/         изображения каталога и портфолио
data/                   локальная база данных SQLite
```

Локальные файлы `data/*.db`, изображения из `static/uploads/*` и временная папка `report_tmp/` не являются обязательной частью исходного кода. Они создаются при работе сайта и не должны попадать в публичный репозиторий вместе с персональными данными клиентов.

## Важное замечание

Файлы в `report_tmp` используются только для локальных проверок и подготовки отчета. Они не управляют рабочей версией сайта.
