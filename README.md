# Praktica3kyrs

Учебный проект сайта ювелирной мастерской для малого бизнеса. Сайт содержит публичные страницы с информацией о мастерской, услугах, каталоге и контактах, а также простую серверную часть для сохранения заявок клиентов.

## Что уже есть

- 12 публичных HTML-страниц.
- Адаптивная верстка для компьютера и телефона.
- Верхнее меню, хлебные крошки и подвал сайта.
- Страница заявки клиента.
- Backend на Flask.
- Хранение заявок в SQLite.
- Простая административная часть для просмотра заявок.
- Вход в админку по паролю.
- Фильтр заявок по статусу обработки.

## Статическая проверка

Большинство страниц можно открыть без запуска сервера. Для этого достаточно открыть файл `index.html` в браузере.

В таком режиме удобно смотреть внешний вид страниц, но форма заявки не будет сохранять данные, потому что для этого нужен Flask.

## Запуск через Flask

Для полноценной проверки сайта нужно запустить `app.py`.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Если Python установлен через Microsoft Store и команда `python` открывает магазин или работает некорректно, можно попробовать:

```powershell
py -3 app.py
```

После запуска сайт обычно доступен по адресу:

```text
http://127.0.0.1:5000/
```

## Основные страницы

- Главная страница: `http://127.0.0.1:5000/`
- Форма заявки: `http://127.0.0.1:5000/request.html`
- Вход администратора: `http://127.0.0.1:5000/admin/login`
- Заявки администратора: `http://127.0.0.1:5000/admin/requests`

## Административный вход

Учебный пароль администратора по умолчанию:

```text
admin
```

Пароль задается в файле `app.py`:

```python
ADMIN_PASSWORD = os.environ.get("ADMIN_PASSWORD", "admin")
```

Если нужно временно изменить пароль без правки кода, перед запуском можно задать переменную окружения:

```powershell
$env:ADMIN_PASSWORD = "new_password"
python app.py
```

## Данные

Заявки сохраняются в локальную базу данных SQLite:

```text
data/site.db
```

Если файла базы нет, приложение создаст его автоматически при запуске.

## Структура проекта

```text
app.py              Flask-приложение и обработка заявок
requirements.txt    зависимости проекта
index.html          главная страница
request.html        форма заявки
static/css/         стили сайта
static/js/          JavaScript для меню и формы
data/               локальная база данных
ADMIN_GUIDE.md      инструкция администратора
```

## Важное замечание

Файлы `admin_snapshot.html` и `login_snapshot.html` находятся в папке `report_tmp` и используются только как сохраненные снимки для отчета. Они не управляют рабочей версией сайта. Живая административная часть формируется в `app.py`.
